# レクチャーノート：法務 ― 知的財産、セキュリティ、労働・取引に関する法規

対応範囲：情報処理安全確保支援士試験（科目A-1）「企業と法務」＞「法務」（知的財産権、セキュリティ関連法規、労働関連・取引関連法規、その他の法律とガイドライン）

---

## 0. 全体像 ― なぜこの分野を学ぶのか

前回のノート（企業活動）では、企業がどう組織され、業務や成果をどう分析・数値化するかを見ました。本ノートでは視点を法律に移し、企業活動やIT技術者の業務を規律する法務の知識を扱います。ストラテジ系の最後を締めくくる分野であり、これまでの経営戦略・企業活動の知識を、法律というルールの側面から裏付ける内容になります。

本ノートは、次の4段階のストーリーで説明します。①まず、発明や著作物といった無形の財産をどう保護するかという知的財産権を学びます。②次に、情報セキュリティ・個人情報・通信に関連する法規を見ます。③次に、労働や業務委託の契約に関する法規を見ます。④最後に、デジタル社会・製品・技術者倫理に関するその他の法律・ガイドラインを扱います。

本分野は科目A-1（共通知識）の出題範囲ですが、個人情報保護法や不正アクセス禁止法などのセキュリティ関連法規は、科目A-2の専門知識でも関連する背景知識として問われることがあります。法律名と「何を保護し、何を規律する法律か」の対応を押さえることが最も重要です。

---

## 1. 発明や著作物をどう保護するか ― 知的財産権

まず、発明・著作物・営業秘密といった無形の財産をどう保護するかという知的財産権の考え方を見ていきます。

### 1.1 知的財産と知的財産権

発明・著作物・デザイン・ブランドなど、人間の創造的活動によって生み出された無形の財産を**知的財産**と呼び、これを法的に保護する権利を**知的財産権**と呼びます。次節以降で扱う著作権や不正競争防止法による保護は、いずれもこの知的財産権の一部にあたります。

### 1.2 著作権

著作物を保護するための法律が**著作権法**です。著作権には2つの側面があり、著作物を複製・上演・公衆送信するなど財産的な利益に関する権利を**著作財産権**、著作者の名誉・意向を守るための権利（氏名表示権、同一性保持権など）を**著作者人格権**と呼びます。著作財産権が「経済的な利益」を守り、譲渡・相続が可能であるのに対し、著作者人格権は「著作者個人の名誉・意向」を守る一身専属の権利で、他人に譲渡できないという違いで区別します。また、著作物を創作した時点で、出願や登録の手続きなしに自動的に著作者へ著作権が発生し帰属するという原則を**原始的帰属**（無方式主義）と呼びます。

### 1.3 営業秘密と不正競争の防止

秘密として管理されている、事業活動に有用な技術上・営業上の情報を**トレードシークレット（営業秘密）**と呼びます。特許のように出願・公開して保護するのではなく、秘密のまま保護する点が特許権との大きな違いです。このトレードシークレットの不正な取得・使用など、公正な競争を害する行為を規制する法律が**不正競争防止法**です。

### 1.4 オープンソースソフトウェアの考え方

ソースコードが公開され、誰でも利用・改変・再配布できるソフトウェアを**OSS（オープンソースソフトウェア）**と呼びます。このOSSの定義・普及を推進する非営利組織が**OSI（Open Source Initiative）**で、OSIが定める、あるソフトウェアがOSSと呼べるための要件を**OSD（Open Source Definition）**と呼びます。OSDの要件を満たすと認定されたライセンスに付与されるマークが**OSI認定マーク**です。OSSという理念があり、それを運営する組織がOSI、具体的な判定基準がOSD、その認定の証がOSI認定マークという階層関係で整理すると覚えやすくなります。

## 2. 情報セキュリティに関連する法規

次に、不正アクセス、個人情報、通信に関連するセキュリティ関連法規を見ていきます。

### 2.1 不正アクセスとサイバー空間の基本法

他人のID・パスワードを無断で使用してシステムに侵入する等の行為を禁止する法律が**不正アクセス禁止法**です。この法律ではカバーしきれない、電子計算機使用詐欺罪や不正指令電磁的記録に関する罪（ウイルス作成罪）など、情報犯罪に関連する規定は**刑法**に含まれます。また、国全体としてのサイバーセキュリティ政策の基本理念・方向性を定める基本法が**サイバーセキュリティ基本法**です。不正アクセス禁止法・刑法が「個別の違法行為を罰する」規定であるのに対し、サイバーセキュリティ基本法は「国としての政策の方向性」を定める、より上位の理念的な法律という違いで整理できます。

### 2.2 個人情報を保護する法律

個人情報の適正な取扱いに関する事業者の義務等を定める法律が**個人情報保護法**です。このうち、人種、信条、病歴など不当な差別・偏見が生じないよう特に配慮を要する個人情報を**要配慮個人情報**と呼び、通常の個人情報よりも厳格な取扱いが求められます。国民一人ひとりに割り振られる12桁の番号を**マイナンバー**と呼び、その利用・管理等を定める法律が**マイナンバー法**です。マイナンバーに紐づく情報は「特定個人情報」として、個人情報保護法よりもさらに厳格な保護が求められます。

### 2.3 通信・プロバイダに関する法規

広告・宣伝を目的とした迷惑メール（スパムメール）の送信を規制する法律が**特定電子メール法**です。インターネット上での情報流通において権利侵害が生じた場合の、**プロバイダ**（**特定電気通信役務提供者**）の損害賠償責任の範囲や、発信者情報の開示請求について定める法律が**プロバイダ責任法**（プロバイダ責任制限法）です。

SNS等のプラットフォーム上での誹謗中傷といった違法情報に、事業者が迅速に対応することを義務付ける法律が**情報流通プラットフォーム対処法**で、プロバイダ責任法の考え方をさらに発展させ、利用者数等が一定規模以上の**大規模特定電気通信役務提供者**に、特に重い対応義務を課します。プロバイダ責任法が「基本的な責任制限の枠組み」であるのに対し、情報流通プラットフォーム対処法は「大規模事業者への対応義務の強化」という発展形にあたります。

このほか、組織犯罪等の捜査のため裁判所の令状に基づき通信を傍受することを認める法律が**通信傍受法**、電子署名に手書きの署名や押印と同等の法的効力を認めるための要件等を定める法律が**電子署名認証法**（電子署名法）です。

## 3. 労働や業務委託に関する法規

続いて、労働者の保護や、業務委託の契約形態に関する法規を見ていきます。

### 3.1 労働に関する法律

労働時間・賃金など、労働条件の最低基準を定める法律が**労働基準法**です。労働者派遣事業の適正な運営や、派遣労働者の保護等を定める法律が**労働者派遣法**で、契約形式上は請負や準委任でありながら、実態としては労働者派遣に該当する（発注者が労働者に直接指揮命令する）状態を**偽装請負**と呼び、労働者派遣法等に違反する行為として問題視されます。

### 3.2 業務委託の契約形態

システム開発などの業務委託契約には、性質の異なる契約形態があります。仕事の完成を約束し、その成果物に対して報酬が支払われる契約を**請負契約**と呼び、受注者は成果物に対する責任（契約不適合責任等）を負います。これに対し、法律行為の遂行を委託する契約を**委任契約**、法律行為でない事務の遂行を委託する契約を**準委任契約**と呼び、システム開発の役務提供（保守・運用等）では準委任契約が多く用いられます。請負契約が「仕事の完成」に責任を持つのに対し、委任契約・準委任契約は「業務の遂行」自体に責任を持ち、成果物の完成そのものは約束しないという違いで区別します。

報酬未払いの際に、他人の物を占有する者がその物に関して生じた債権の弁済を受けるまでその物を留置できる権利を**留置権**と呼びます。こうした契約類型を、システム開発の各工程でどう使い分けるべきかを示した、経済産業省策定のひな形文書が**情報システム・モデル取引・契約書**です。

### 3.3 下請け取引の適正化

親事業者が下請事業者に対して優越的地位を濫用しないよう、代金の支払い遅延の禁止等を定める法律が**下請法**です。偽装請負が「労働者の使用実態」に関する問題であるのに対し、下請法は「取引条件の公正さ」に関する問題を扱う点で異なります。

### 3.4 ソフトウェアの利用契約

ソフトウェアの使用を許諾する権利を**ライセンス**、その許諾条件を定めた契約を**ライセンス契約**と呼びます。代表的な契約形態には、次のものがあります。

| 契約形態 | 内容 |
|---|---|
| **サイトライセンス** | 特定の事業所・拠点単位で包括的に利用を許諾する |
| **ボリュームライセンス** | 一定数量のライセンスをまとめて購入する契約形態 |
| **サーバライセンス** | サーバ単位で利用を許諾する |
| **サブスクリプション** | 利用期間に応じて対価を支払う、都度更新型のライセンス形態 |
| **シュリンクラップ契約** | パッケージの開封をもって、利用許諾条件に同意したとみなす契約形態 |

業務上知り得た秘密情報を第三者に漏らしてはならないという義務を**守秘義務**と呼び、契約（秘密保持契約等）や法律により課されます。

## 4. その他の法律とガイドライン

最後に、デジタル社会、製品・環境、通信事業、技術者倫理に関するその他の法律・ガイドラインを見ていきます。

### 4.1 デジタル社会と電子文書

デジタル社会の形成に関する基本理念・施策の方向性を定める法律が**デジタル社会形成基本法**です。国税関係の帳簿書類を一定の要件のもとで電子データのまま保存することを認める法律が**電子帳簿保存法**、民間事業者等に法令で保存が義務付けられている書面を電子データとして保存することを容認する法律が**e-文書法**です。電子帳簿保存法が「国税関係」に特化した規定であるのに対し、e-文書法はより幅広い分野の書面を対象とする一般的な規定という関係で区別します。

### 4.2 製品と環境に関する法律

製造物の欠陥によって生じた被害について、製造業者の損害賠償責任を定める法律が**製造物責任法（PL法）**です。家電等の特定の製品についてリサイクルを義務付ける法律群を総称して**リサイクル法**と呼び、製品の設計・製造段階から資源の有効利用やリサイクルへの配慮を求める法律が**資源有効利用促進法**です。また、電子・電気機器に含まれる特定の有害物質の使用を制限する、欧州連合（EU）の指令が**RoHS指令**です。

### 4.3 通信事業の規律

電気通信事業の運営について定める法律が**電気通信事業法**です。この法律では、事業の規模等に応じて「届出」または「登録」のいずれかの手続きを行う電気通信事業者を、それぞれ**届出電気通信事業者**、**登録電気通信事業者**として区分しています。

### 4.4 技術者としての倫理

技術者が専門家として社会に対して負うべき責任・倫理観を**技術者倫理**と呼びます。これに対し、集団での意思決定において同調圧力等により、個人では行わないような不合理な結論に至ってしまう現象を**集団思考**（グループシンク）と呼びます。技術者倫理が「個人の責任感」の問題であるのに対し、集団思考は「組織・集団としての意思決定」が陥りやすい罠として、対比的に位置づけられます。

## 5. 試験対策まとめ（重要ポイント）

- **著作財産権 と 著作者人格権**：経済的な利益を守るか、著作者個人の名誉・意向を守るかの違い。後者は譲渡不可。
- **OSS と OSI と OSD と OSI認定マーク**：理念（OSS）→運営組織（OSI）→判定基準（OSD）→認定の証（OSI認定マーク）という階層関係。
- **個人情報保護法 と マイナンバー法**：一般的な個人情報の保護か、それよりも厳格な特定個人情報の保護かの違い。
- **プロバイダ責任法 と 情報流通プラットフォーム対処法**：基本的な責任制限の枠組みか、大規模事業者への対応義務を強化した発展形かの違い。
- **請負契約 と 委任契約／準委任契約**：仕事の完成に責任を持つか、業務の遂行自体に責任を持つかの違い。
- **偽装請負 と 下請法**：労働者の使用実態に関する問題か、取引条件の公正さに関する問題かの違い。
- **電子帳簿保存法 と e-文書法**：国税関係の書類に限定されるか、より幅広い分野の書面が対象かの違い。
- **技術者倫理 と 集団思考**：個人の責任感の問題か、組織・集団の意思決定が陥りやすい罠かの違い。
