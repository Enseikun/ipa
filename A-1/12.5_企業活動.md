# レクチャーノート：企業活動 ― 経営・組織論、IE・OR、会計・財務

対応範囲：情報処理安全確保支援士試験（科目A-1）「経営戦略」＞「企業活動」（経営・組織論、業務分析・データ利活用〈IE・OR〉、会計・財務）

---

## 0. 全体像 ― なぜこの分野を学ぶのか

前回のノート（ビジネスインダストリ）では、各産業を支える具体的な情報システムを見ました。本ノートでは視点を企業そのものに戻し、企業がどう組織され、業務やデータをどう定量的に分析し、そして活動の成果をどう数値で捉えるかという、企業活動の基礎知識を扱います。

本ノートは、次の3段階のストーリーで説明します。①まず、企業がどう組織を構成し、経営を統治するかという経営・組織論を学びます。②次に、業務やデータを定量的に分析するための手法群であるIE・ORを見ます。③最後に、企業活動の成果を数値で捉える会計・財務の基礎を扱います。

本分野は科目A-2の出題対象には含まれない科目A-1のみの分野ですが、これまでのストラテジ系の中でも用語数が特に多い分野です。組織形態や経営層の略称、対になる分析手法・会計処理の違いを、それぞれ「何を軸に区別しているか」で整理しながら押さえていきます。

---

## 1. 組織をどう構成し、経営を統治するか ― 経営・組織論

まず、企業の組織構成と、経営を統治するための仕組みを見ていきます。

### 1.1 経営管理サイクルと組織形態

計画（Plan）・実行（Do）・評価（Check）・改善（Act）の4段階を繰り返すことで業務を継続的に改善していくマネジメントサイクルを**PDCA**と呼びます。この管理サイクルを実行する主体である組織の形態には、次のような種類があります。

| 組織形態 | 特徴 |
|---|---|
| **職能別組織** | 営業・製造・人事といった職能（機能）ごとに部門を編成する |
| **事業部制組織** | 製品や地域などの単位で事業部を設け、各事業部が独立採算で意思決定を行う |
| **カンパニ制** | 事業部制をさらに進め、各事業部を独立した会社のように扱い、投下資本に対する責任まで持たせる |
| **プロジェクト制** | 特定のプロジェクトの遂行のために、必要な人材を一時的に集めて編成する |
| **アメーバ組織** | 小集団（アメーバ）ごとに独立採算制を敷き、全員が経営者意識を持って活動する |
| **ライン・スタッフ組織** | 実際の業務を遂行するライン部門と、それを専門知識で支援するスタッフ部門から成る |

職能別組織から事業部制、カンパニ制へと進むにつれて、各単位が持つ意思決定・採算の権限が段階的に大きくなっていくという発展の流れで捉えると整理しやすくなります。

### 1.2 経営層の役割分担

経営層は、それぞれ異なる責任領域を担う役職に分かれています。

| 役職 | 役割 |
|---|---|
| **CEO（最高経営責任者）** | 企業全体の経営方針を決定する最高責任者 |
| **COO（最高執行責任者）** | CEOが決定した方針に基づき、日々の業務執行を統括する |
| **CIO（最高情報責任者）** | 情報システム・IT戦略全般を統括する |
| **CISO（最高情報セキュリティ責任者）** | 情報セキュリティに関する戦略・対策を統括する |
| **CPO（最高個人情報保護責任者）** | 個人情報保護に関する方針・対策を統括する |

CEOが経営全体の方針を、COOがその執行を担うのに対し、CIO・CISO・CPOはそれぞれ情報・セキュリティ・個人情報保護という専門領域に特化した責任者であるという役割の広さの違いで区別します。

### 1.3 企業の社会的な責任と統治

企業経営を監視・統制し、株主等のステークホルダーの利益を守るための仕組みを**コーポレートガバナンス**と呼びます。これに対し、投資家に対して経営状況等の情報を提供する活動を**IR（投資家向け広報）**、企業が利益追求だけでなく社会に対して果たすべき責任を**CSR（企業の社会的責任）**と呼びます。コーポレートガバナンスが「内部からの統治の仕組み」、IRが「投資家という外部への情報発信」、CSRが「社会全体への責任」という、それぞれ異なる方向を向いた活動として整理できます。また、企業全体の信頼・イメージという無形の資産を**コーポレートブランド**と呼び、これらの活動全体を通じて築かれるものと位置づけられます。

### 1.4 非常時への備えと働き方

災害等の緊急事態が発生した際にも、重要な事業を中断させない、または早期に復旧させるための計画を**BCP（事業継続計画）**と呼び、このBCPを策定するだけでなく継続的に維持・改善していくマネジメント活動全体を**BCM（事業継続マネジメント）**と呼びます。BCPが「計画そのもの」であるのに対し、BCMは「その計画を運用管理する仕組み」であるという関係で区別します。働き方の制度としては、実際の労働時間によらず、あらかじめ定めた時間を働いたものとみなす**裁量労働制**があります。

### 1.5 人を動かす行動科学

人間の行動を科学的に分析し、組織のマネジメントに活かす学問領域を**行動科学**と呼びます。集団を目標達成に導く影響力である**リーダーシップ**については、次のような理論があります。

| 理論 | 内容 |
|---|---|
| **PM理論** | Performance（目標達成）機能とMaintenance（集団維持）機能の2軸でリーダーシップスタイルを分類する |
| **SL理論** | 部下の成熟度に応じて、リーダーシップのスタイルを変えるべきとする理論 |
| **リーダーシップ特性論** | 優れたリーダーに共通する資質・特性に着目する理論 |

リーダーシップの発揮を支えるスキルとしては、意思疎通を図る**コミュニケーション**、動機づけを行う**モチベーション**、利害の調整を図る**ネゴシエーション**、会議等の進行を支援する**ファシリテーション**があります。また、経済産業省が策定した、企業がDXを推進する上での経営者の役割等を示す指針を**デジタルガバナンスコード**と呼びます。1.3節で見たコーポレートガバナンスの考え方を、デジタル・DXの文脈に適用したものとして位置づけられます。

## 2. 業務やデータを定量的に分析する ― IE・OR

次に、業務やデータを数理的・統計的に分析し、意思決定を助ける手法群を見ていきます。

### 2.1 業務分析の2つの学問領域

作業やプロセスを分析し、効率化を図る工学的手法を**IE（インダストリアル・エンジニアリング）**と呼び、数理的モデルを用いて経営上の意思決定を最適化する手法群を**OR（オペレーションズ・リサーチ）**と呼びます。ORが広く数理的な意思決定手法全般を指すのに対し、IEはその中でも作業・工程の効率化に特化した分野という関係で捉えられます。

### 2.2 品質を管理する

製品・サービスの品質を一定水準に保つための活動を**品質管理**と呼びます。これを製造部門だけでなく全社的に展開する考え方が**TQC（全社的品質管理）**で、さらに顧客満足を中心に経営全体で品質向上に取り組む、より発展した考え方が**TQM（総合的品質管理）**です。TQCが「全社的な品質管理活動」であるのに対し、TQMは「経営戦略として品質を捉える発展形」という関係で整理します。

品質管理で用いられる代表的な手法群として、パレート図や特性要因図など数値データを統計的に分析する**QC七つ道具**と、数値化しにくい言語データを整理・分析する**新QC七つ道具**があります。QC七つ道具が「定量データ」を扱うのに対し、新QC七つ道具は「定性・言語データ」を扱うという対比で区別します。

### 2.3 意思決定を助ける手法

意思決定の選択肢とその結果を木構造で図示し評価する手法を**デシジョンツリー**と呼びます。事象の関係を図示して整理する手法としては、「なぜそうなったか」という因果関係を図示する**原因結果型関連図**と、「何のために何をするか」という目的と手段の関係を図示する**目的手段型関連図**があります。また、複数の専門家に匿名でアンケートを繰り返し実施し、意見を収束させていく予測・意思決定手法を**デルファイ法**、制約条件のもとで利益の最大化やコストの最小化といった目的関数を最適化する数理計画手法を**線形計画法**と呼びます。

### 2.4 在庫をどう管理するか

在庫管理の代表的な発注方式には、次のものがあります。

| 方式 | 内容 |
|---|---|
| **定期発注法** | あらかじめ定めた一定の間隔で発注し、発注量はそのつど需要予測に基づいて決定する |
| **定量発注法** | 在庫量があらかじめ定めた一定水準（発注点）まで減ったら発注する |
| **発注点法** | 定量発注法における、発注を行う基準在庫量の考え方 |

定期発注法が「発注の間隔」を固定するのに対し、定量発注法（発注点法）は「発注のタイミング（在庫量の水準）」を固定するという、着目する軸の違いで区別します。いずれの方式でも、発注費用と保管費用の合計が最小になる、最も経済的な1回あたりの発注量を**経済的発注量**として算出し、判断材料とします。

### 2.5 競争と均衡を数理的にとらえる ― ゲーム理論

複数の主体（プレイヤー）が互いに影響し合う状況での意思決定を分析する理論を**ゲーム理論**と呼びます。2人のプレイヤーの利得の合計が常に一定（ゼロサム）になるゲームを**2人零和ゲーム**と呼び、各プレイヤーの戦略の組み合わせごとに得られる利得を一覧にした表を**利得表**と呼びます。

戦略の選び方には、一つの戦略を確定的に選択する**純粋戦略**と、複数の戦略を一定の確率に従って確率的に選択する**混合戦略**があります。意思決定の原理としては、自分が選べる戦略の中で最悪の場合の利得が最も大きくなる戦略を選ぶ**マクシミン原理**（悲観的な考え方）と、逆に最良の場合の利得が最も大きくなる戦略を選ぶ**マクシマックス原理**（楽観的な考え方）が対比されます。また、相手の視点から見て自分に与える損失を最小化しようとする**ミニマックス原理**は、マクシミン原理と表裏一体の関係にあります。どのプレイヤーも自分だけ戦略を変えても利得を改善できない、安定した戦略の組み合わせの状態を**ナッシュ均衡**と呼びます。

### 2.6 検査の精度をどう評価するか ― OC曲線

抜取検査において、ロットの不良率とそのロットが合格と判定される確率との関係を示す曲線を**OC曲線（検査特性曲線）**と呼びます。この検査には、本来合格とすべき良品のロットを誤って不合格と判定してしまう**第一種の誤り（生産者危険）**と、本来不合格とすべき不良品のロットを誤って合格と判定してしまう**第二種の誤り（消費者危険）**の、2種類の誤りがあります。第一種の誤りが「生産者側の損失」につながるのに対し、第二種の誤りは「消費者側の損失」につながるという、誤りが及ぼす影響の違いで区別します。

## 3. 企業活動の成果を数値でとらえる ― 会計・財務

最後に、これまで見てきた企業活動の成果を、会計・財務の視点から数値でとらえる方法を見ていきます。

### 3.1 会計の2つの目的

株主や債権者など外部の利害関係者に向けて経営状況を報告するための会計を**財務会計**と呼び、経営者が社内の意思決定に活用するための会計を**管理会計**と呼びます。財務会計が「外部への報告」を目的とするのに対し、管理会計は「内部の意思決定」を目的とするという対比で整理します。

### 3.2 財務諸表の基本

ある時点における企業の資産・負債・純資産の状態を示す財務諸表を**B/S（貸借対照表）**と呼び、一定期間における企業の収益・費用・利益の状況を示す財務諸表を**P/L（損益計算書）**と呼びます。B/Sが「ある時点のストック（残高）」を示すのに対し、P/Lは「一定期間のフロー（流れ）」を示すという違いで区別します。これらの財務諸表を作成する前段階で、総勘定元帳の各勘定科目の残高を集計した検証用の表が**残高試算表**です。

### 3.3 資産価値をどう費用化するか ― 減価償却

固定資産の取得費用を、使用期間にわたって費用として配分していく会計処理を**減価償却**と呼び、代表的な方法として、毎期一定の金額を償却する**定額法**と、未償却残高に一定の率を掛けて償却する（初期の償却費が大きい）**定率法**があります。

### 3.4 利益の構造を分析する ― 損益分岐点分析

売上高と費用の関係から、利益と損失が分かれる売上高の水準（損益分岐点）を分析する手法を**損益分岐点分析**と呼びます。グラフ上では、売上高を表す**売上高線**、売上高にかかわらず一定にかかる固定費を表す**固定費線**、固定費に変動費を加えた**総費用**線を描き、売上高線と総費用線が交わる点が損益分岐点にあたります。売上高から変動費を差し引いた**限界利益**で固定費をどれだけ賄えるかが、損益分岐点分析の基本的な考え方です。

### 3.5 在庫の評価方法（棚卸評価）

期末に残っている在庫（棚卸資産）の金額を評価する会計処理を**棚卸評価**と呼び、代表的な方法として次のものがあります。

| 方法 | 内容 |
|---|---|
| **先入先出法** | 先に仕入れたものから先に払い出したとみなして評価する |
| **後入先出法** | 後に仕入れたものから先に払い出したとみなして評価する |
| **移動平均法** | 仕入れの都度、平均単価を計算し直して評価する |
| **総平均法** | 一定期間の仕入れ全体の平均単価で評価する |

こうした棚卸資産（仕掛品・製品）の評価の基礎となるのが、製品を製造するためにかかった原価である**製造原価**です。

### 3.6 投資の意思決定と収益性を測る

一定期間における現金の増減を**キャッシュ・フロー**と呼びます。これは損益計算書上の利益とは異なり、実際の現金の出入りを示す点が特徴です。投資の可否を判断する手法としては、投資によって将来得られるキャッシュ・フローを現在価値に割り引いて合計し投資額と比較する**正味現在価値法**と、投資額を投資によって得られるキャッシュ・フローで何年で回収できるかによって判断する**回収期間法**があります。正味現在価値法が「お金の時間的価値を考慮する」より精緻な手法であるのに対し、回収期間法は「何年で元が取れるか」というシンプルな指標である点で対比できます。

### 3.7 経営の効率性を測る指標

経営の効率性・収益性を測る代表的な財務指標として、次のものがあります。

| 指標 | 内容 |
|---|---|
| **ROA（総資産利益率）** | 総資産に対してどれだけ利益を上げたか |
| **ROE（自己資本利益率）** | 自己資本（株主の持ち分）に対してどれだけ利益を上げたか |
| **ROI（投資利益率）** | 投下した資本に対してどれだけ利益を上げたか |

ROA・ROE・ROIは、それぞれ「総資産全体」「自己資本」「投じた資本」という異なる分母に対する収益性を測る指標です。前回のノートで扱ったKPI（重要業績評価指標）の代表例として、こうした財務指標も経営目標の達成度を測るために用いられます（前回接続）。

## 4. 試験対策まとめ（重要ポイント）

- **職能別組織〜アメーバ組織**：職能別→事業部制→カンパニ制と進むにつれ、各単位が持つ意思決定・採算の権限が大きくなる発展の流れ。
- **CEO／COO と CIO／CISO／CPO**：企業全体の経営・執行を担うか、情報・セキュリティ・個人情報保護という専門領域を担うかの違い。
- **BCP と BCM**：緊急事態への計画そのものか、その計画を継続的に運用管理する仕組みかの違い。
- **TQC と TQM**：全社的な品質管理活動か、経営戦略として品質を捉える発展形かの違い。
- **QC七つ道具 と 新QC七つ道具**：定量データを扱うか、定性・言語データを扱うかの違い。
- **定期発注法 と 定量発注法（発注点法）**：発注の間隔を固定するか、発注のタイミング（在庫水準）を固定するかの違い。
- **マクシミン原理 と マクシマックス原理**：最悪に備える悲観的な考え方か、最良を狙う楽観的な考え方かの違い。
- **第一種の誤り（生産者危険） と 第二種の誤り（消費者危険）**：良品を誤って不合格とするか、不良品を誤って合格とするかの違い。
- **B/S と P/L**：ある時点のストックか、一定期間のフローかの違い。
- **定額法 と 定率法**：毎期一定額を償却するか、一定率で償却し初期の償却費が大きいかの違い。
- **先入先出法 と 後入先出法**：古い在庫から払い出したとみなすか、新しい在庫から払い出したとみなすかの違い。
- **正味現在価値法 と 回収期間法**：お金の時間的価値を考慮する精緻な手法か、何年で元が取れるかというシンプルな指標かの違い。
- **ROA／ROE／ROI**：総資産、自己資本、投下資本という、それぞれ異なる分母に対する収益性の指標。
