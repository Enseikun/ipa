# レクチャーノート：標準化 ― マネジメント規格、技術標準、標準化組織

対応範囲：情報処理安全確保支援士試験（科目A-1）「企業と法務」＞「標準化関連」（開発と取引・データ交換の標準化、ソフトウェア・データの標準化、標準化組織）

---

## 0. 全体像 ― なぜこの分野を学ぶのか

前回のノート（法務）では、企業活動を規律する法律を見ました。本ノートでは視点を法律から規格に移し、企業や技術者が共通のルールに従って開発・取引・データ交換を行うための標準化の知識を扱います。

本ノートは、次の3段階のストーリーで説明します。①まず、品質・環境・サービスマネジメントに関する国際規格群を学びます。②次に、ソフトウェアやデータ形式に関する技術標準を見ます。③最後に、これらの規格を実際に策定している標準化組織を見ます。

本分野は科目A-1（共通知識）の出題範囲で、略称の多い組織名・規格名を区別することが中心になります。「どの分野を対象とする規格・組織か」という軸で整理すると、暗記の効率が上がります。

## 1. 開発と取引・データ交換の標準化

まず、企業の品質・環境・サービスマネジメントを保証するための国際規格群を見ていきます。

### 1.1 品質と環境を保証する国際規格

組織が一貫して顧客要求を満たす製品・サービスを提供する仕組みを認証するための国際規格群が**ISO 9000シリーズ**で、その要求事項を定めた規格の日本語版が**JIS Q 9001**です。これに対し、組織の活動が環境に与える影響を管理する仕組みを認証するための国際規格群が**ISO 14000シリーズ**で、代表的な規格が**ISO 14001**とその日本語版である**JIS Q 14001**です。ISO 9000が「品質」を対象とするのに対し、ISO 14000は「環境」を対象とするという違いで区別します。

### 1.2 サービスマネジメントの国際規格

以前のノート（サービスマネジメント）で扱った、ITサービスマネジメントに関する国際規格が**ISO/IEC 20000シリーズ**です。要求事項を定めた**ISO/IEC 20000-1**と、実践のための手引きを示した**ISO/IEC 20000-2**から成り、それぞれの日本語版が**JIS Q 20000-1**、**JIS Q 20000-2**です（前回接続）。こうした国際規格の認証機関の一つとして、**BSI（British Standards Institution、英国規格協会）**があります。

## 2. ソフトウェア・データの標準化

次に、ソフトウェアの分散処理やデータ形式に関する技術標準を見ていきます。

### 2.1 分散システムを実現する標準

異なるプログラミング言語・プラットフォーム上のオブジェクト同士が、ネットワークを介して相互に呼び出しを行うための標準規格が**CORBA（Common Object Request Broker Architecture）**です。この中でオブジェクト間の呼び出し要求を仲介する仕組みを**ORB（Object Request Broker）**と呼びます。CORBAが規格全体の名称であるのに対し、ORBはその呼び出しの仲介を実現する中核的な機能にあたるという関係で区別します。また、Java言語における、企業システム向けに部品化されたソフトウェアコンポーネントの規格が**EJB（Enterprise JavaBeans）**です。

### 2.2 画像・映像ファイルの標準規格

代表的な画像・映像のファイル形式には、次のものがあります。

| 規格 | 内容 |
|---|---|
| **JPEG** | 写真等の自然画像に適した、非可逆圧縮の静止画像フォーマット |
| **GIF** | 256色までの限られた色数で、可逆圧縮に対応する静止画像フォーマット。簡単なアニメーションも扱える |
| **PNG** | GIFの特許問題を背景に開発された、可逆圧縮に対応する静止画像フォーマット |
| **MPEG** | 音声・動画データの圧縮に関する標準規格群 |

JPEGが「非可逆圧縮」で写真のようなデータ量の多い自然画像に向くのに対し、GIF・PNGは「可逆圧縮」でイラストや図表のような画像に向くという、圧縮方式と用途の対応で整理します。

### 2.3 情報を素早く読み取る ― QRコード

縦横二方向に情報を持たせることで、従来のバーコード（一次元コード）よりも多くの情報量を高速に読み取れる二次元コードを**QRコード**と呼びます。日本の企業が開発した規格で、現在では国際標準としても広く採用されています。

## 3. 標準化組織 ― 誰が規格を定めるか

最後に、ここまで見てきた規格を実際に策定している、国際・各国・インターネット分野の標準化組織を見ていきます。

### 3.1 国際的な標準化組織

分野の異なる、代表的な国際標準化組織は次のとおりです。

| 組織 | 対象分野 |
|---|---|
| **ISO（国際標準化機構）** | 工業製品や品質・環境マネジメント等、幅広い分野の国際規格を策定する |
| **IEC（国際電気標準会議）** | 電気・電子技術分野の国際規格を策定する |
| **ITU（国際電気通信連合）** | 電気通信分野の国際的な標準化・調整を行う、国連の専門機関 |

ISOが「工業製品全般」、IECが「電気・電子技術」、ITUが「電気通信」という、それぞれ異なる産業分野を対象とする国際機関として整理します。このITUの内部には、電気通信の標準化を担当する**ITU-T**と、無線通信の標準化を担当する**ITU-R**という下部組織があります。

### 3.2 各国・地域の標準化団体

電気・電子工学分野の学会であり、LANの規格（IEEE802シリーズ）など数多くの技術標準を策定する**IEEE（米国電気電子学会）**、アメリカの国家標準を策定する**ANSI（米国国家規格協会）**、イギリスの国家標準を策定する**BSI（英国規格協会）**（前章の認証機関としての役割と合わせて再掲）があります。日本の国家規格は**JIS（日本産業規格）**と呼ばれ、情報処理分野には**JIS X**、マネジメントシステム分野には**JIS Q**という分類記号が付与されます。このJISを策定・審議する日本の機関が**JISC（日本産業標準調査会）**です。IEEE・ANSI・BSIがそれぞれの国・分野の標準化団体であるのに対し、JISCは日本におけるその役割を担う機関という対応関係で整理できます。

### 3.3 インターネットの標準化組織

インターネットで使われる技術の標準化を行う組織が**IETF（Internet Engineering Task Force）**で、インターネットの技術的な方向性を監督する、IETFの上位組織が**IAB（Internet Architecture Board）**です。IETFが策定するインターネット関連技術の標準仕様書を**RFC（Request For Comments）**と呼びます。IETFが「標準化を行う組織」であるのに対し、RFCは「その成果として公開される文書」という、組織と成果物の関係で整理します。

## 4. 試験対策まとめ（重要ポイント）

- **ISO 9000シリーズ と ISO 14000シリーズ**：品質マネジメントか、環境マネジメントかという対象の違い。
- **ISO/IEC 20000-1 と 20000-2**：要求事項（認証の対象）か、実践のための手引きかという違い（前回のサービスマネジメントと接続）。
- **CORBA と ORB**：規格全体の名称か、その中核の仲介機能かという違い。
- **JPEG と GIF／PNG**：非可逆圧縮で写真向きか、可逆圧縮でイラスト向きかという違い。
- **ISO と IEC と ITU**：工業製品全般、電気・電子技術、電気通信という対象分野の違い。
- **ITU-T と ITU-R**：有線を含む電気通信の標準化か、無線通信の標準化かという違い。
- **IEEE／ANSI／BSI と JISC**：米国・英国等の標準化団体と、それに対応する日本の機関という対応関係。
- **IETF と IAB と RFC**：標準化を行う組織か、その上位の監督組織か、成果物としての標準仕様書かという関係。
