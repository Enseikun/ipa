## 0. 全体像 ― なぜこの分野を学ぶのか

これまでのノートでは、プロセッサ（頭脳）とメモリ（記憶）という、コンピュータ内部の中核部分を見てきました。本ノートで扱うのは、①記憶装置の信頼性・拡張性を高める**RAID**、②プロセッサと周辺機器を接続する**入出力インタフェース**、③実際にデータを蓄える**補助記憶装置**という3つのテーマです。いずれも「限られた装置の性能・信頼性・容量をどう工夫して高めるか」という共通のモチベーションでつながっています。

出題傾向としては、RAIDの各レベルの仕組みと特徴の対比、USB・IEEE1394などインタフェースの規格名と速度・用途の対応、補助記憶メディアの種類と特徴が、知識問題として繰り返し出題される定番論点です。

## 1. RAID ― 複数のディスクで信頼性・性能を高める

### 1.1 RAIDの基本発想

ハードディスクなどの記憶装置は、単体では容量にも信頼性にも限界があります。**RAID（Redundant Arrays of Inexpensive Disks）**は、複数台のディスクを組み合わせて1つの論理的なディスクとして扱うことで、性能（速度）や信頼性（耐障害性）を高める技術です。RAIDにはレベル（方式）がいくつかあり、それぞれ「速度重視」「信頼性重視」「両立」という異なる特徴を持ちます。

### 1.2 ストライピングとRAID0

RAIDの根底にある基本技術の1つが**ストライピング**です。1つのデータを細かく分割し、複数のディスクに分散して同時に書き込む（あるいは同時に読み出す）ことで、実効的な読み書き速度を向上させる仕組みです。前回のノートで扱った「メモリインタリーブ」と同じ発想を、ディスクの世界で実現したものと考えると理解しやすいでしょう。

**RAID0**は、このストライピングのみを行う方式です。速度は大幅に向上しますが、データの複製（冗長性）を一切持たないため、1台でもディスクが故障するとデータ全体が失われてしまいます。「RAIDという名前はついているが、実は信頼性を高める仕組みを持たない」という点が試験でも問われるポイントです。

### 1.3 ミラーリングとRAID1

ストライピングとは異なるアプローチが**ミラーリング**です。同じデータを2台（以上）のディスクに全く同じ内容で複製して書き込む方式で、片方のディスクが故障しても、もう片方のディスクにそのままデータが残っているため、システムを止めずにデータを守ることができます。

**RAID1**は、このミラーリングのみを行う方式です。信頼性は高い一方、実質的に使える容量はディスク台数の半分（2台構成なら半分）になってしまうという特徴があります。「RAID0＝速度重視・冗長性なし」「RAID1＝信頼性重視・容量効率が悪い」という対比がまず押さえるべき基本形です。

### 1.4 パリティ付きストライピングとRAID5

RAID0の速度とRAID1の信頼性を、より効率よく両立させようとするのが**パリティ付きストライピング**という考え方です。データをストライピングして複数ディスクに分散する際、データそのものに加えて、前回のノートで扱った**パリティ**（誤り検出のための情報）を計算し、これも分散して書き込んでおきます。1台のディスクが故障しても、残りのディスクのデータとパリティから、故障したディスクの内容を計算によって復元できます。

**RAID5**は、このパリティ付きストライピングを行う方式です。RAID1のようにディスク台数を丸ごと複製する必要がないため容量効率が良く、かつ1台までのディスク故障には耐えられるという、速度・容量効率・信頼性のバランスが取れた方式として広く使われています。

### 1.5 ホットスペアディスク

RAID5などで1台のディスクが故障した場合、そのままでは「あと1台故障したらデータが失われる」危険な状態が続きます。この復旧を迅速に行うための仕組みが**ホットスペアディスク**（予備ディスク）です。あらかじめシステムに待機させておいた予備のディスクに、故障を検知すると自動的に切り替えてデータの再構築（リビルド）を開始することで、人手を介さずすぐに冗長性のある状態へ復旧できます。

### 1.6 RAID0+1／RAID1+0（RAID10）

RAID0（速度）とRAID1（信頼性）を、単一レベルではなく**組み合わせて（多段構成で）**両方の利点を得ようとする方式もあります。

- **RAID0+1**：まずストライピング（RAID0）でグループを構成し、そのグループ全体をミラーリング（RAID1）する方式。
- **RAID1+0（RAID10）**：まずミラーリング（RAID1）でペアを構成し、そのペアを複数組ストライピング（RAID0）する方式。

両者は似ていますが、耐障害性に違いがあります。RAID1+0は、あるペア内の1台が故障しても、そのペアの相方さえ生きていれば他のペアには影響しないため、複数台の故障にも比較的強い構成になります。一方RAID0+1は、片側のストライピンググループ内で1台でも故障すると、そのグループ全体が実質的に使えなくなり、もう片方のグループだけで支える状態になるため、RAID1+0に比べて耐障害性がやや劣るとされています。「組み合わせる順序（先にミラーか、先にストライピングか）によって耐障害性が変わる」という点が試験で問われる着眼点です。

### 1.7 RAID6

RAID5は「1台までのディスク故障」には耐えられますが、復旧作業（リビルド）中にもう1台が故障すると、データを失ってしまうリスクがあります。ディスクの大容量化が進むほどリビルドには時間がかかり、このリスクは無視できなくなります。

**RAID6**は、パリティを**2種類**計算して分散配置することで、**同時に2台までのディスク故障**に耐えられるようにした方式です。RAID5よりもさらに信頼性を高めた発展形として位置づけられます。「RAID5＝パリティ1つ・1台故障まで耐える」「RAID6＝パリティ2つ・2台故障まで耐える」という対比で整理しましょう。

## 2. 入出力インタフェース ― プロセッサと周辺機器のつなぎ方

### 2.1 シリアル伝送とパラレル伝送

プロセッサと周辺機器（あるいは装置内部の回路同士）がデータをやり取りする際の、信号の送り方の基本形として、次の2つがあります。

- **パラレル伝送**：複数のビットを、複数の信号線を使って同時に（並行して）送る方式。1回の転送で多くのビットを送れるため理論上は高速ですが、信号線が増えるほど配線間の信号到達タイミングのずれ（スキュー）や干渉が問題になり、高速化・長距離化には限界があります。
- **シリアル伝送**：1本の信号線を使い、ビットを1つずつ順番に（直列に）送る方式。1回に送れるビット数は少ないものの、配線がシンプルで信号のタイミングずれの問題が少ないため、非常に高い周波数で送ることができ、結果として現在の主要なインタフェース（USB、SATA、IEEE1394など）の多くはシリアル伝送を採用しています。

「昔はパラレルが主流だったが、高速化の限界からシリアルが主流になった」という技術の流れとして理解しておくと、後続の各規格の位置づけが把握しやすくなります。

### 2.2 USB

**USB（Universal Serial Bus）**は、パソコンと周辺機器（マウス、キーボード、プリンタ、外部ストレージなど）を接続する、現在最も広く使われているシリアル伝送方式のインタフェースです。規格の世代によって転送速度のモードが分かれています。

| モード | 概要 |
|---|---|
| **ロースピードモード** | USB 1.0/1.1世代の低速モード。マウス・キーボードなど低速で十分な機器向け |
| **フルスピードモード** | USB 1.0/1.1世代の標準モード |
| **ハイスピードモード** | USB 2.0で追加された高速モード |
| **スーパースピードモード** | USB 3.0以降で追加された、さらに高速なモード |

世代が進むごとに新しいモードが追加され、転送速度が大きく向上してきた、という流れを押さえておきましょう。

USBの普及を支えた重要な特徴が、次の2つです。

- **プラグアンドプレイ**：周辺機器を接続すると、OSが自動的にその機器を認識し、必要なドライバの設定などを自動的に行ってくれる仕組み。利用者が手動で複雑な設定を行う必要がありません。
- **ホットプラグ**：コンピュータの電源を入れたまま（稼働中に）機器の接続・取り外しができる仕組み。USBはこの2つの特徴を備えているため、ケーブルを挿すだけですぐに機器が使えるようになっています。

### 2.3 IEEE 1394

**IEEE 1394**は、USBと同様にシリアル伝送によるコンピュータと周辺機器の接続規格で、主にビデオカメラなど、高速かつ安定したデータ転送が求められるマルチメディア機器の接続に使われてきました（「FireWire」「i.LINK」といった名称でも知られます）。USBと同じくプラグアンドプレイ・ホットプラグに対応している点が共通しますが、機器間を数珠つなぎに接続する**デイジーチェーン**接続が可能である点が特徴の一つとして挙げられます（USBもハブを介した木構造での多段接続が可能ですが、IEEE1394は機器同士を直接連鎖的に接続できる点が対比されます）。

### 2.4 SCSIとデイジーチェーン

**SCSI（Small Computer System Interface）**は、パソコンとハードディスクやスキャナなどの周辺機器を接続するための、歴史的に重要なインタフェース規格です。複数の機器を1本のケーブルで数珠つなぎに接続していく**デイジーチェーン**方式を採用し、各機器にはID番号を割り当てて識別する仕組みを持っていました。現在では後述のSATAなどに主流の座を譲っていますが、「デイジーチェーン接続」という接続方式の代表例として、IEEE1394とあわせて理解しておくとよい規格です。

### 2.5 SATA、ATA・IDE

コンピュータ内部でハードディスクやSSD（後述）を接続するためのインタフェースとして、次のような規格があります。

- **ATA（AT Attachment）／IDE（Integrated Drive Electronics）**：古くから使われてきたパラレル伝送方式の内部ストレージ接続規格。ほぼ同義で使われることが多い用語です。
- **SATA（Serial ATA）**：ATA（パラレル伝送）を、シリアル伝送に置き換えて高速化・ケーブルの細径化を実現した後継規格。現在のパソコン内部のハードディスク・SSD接続の主流です。

ここでも「パラレル（ATA/IDE）からシリアル（SATA）へ」という、前述したシリアル化の流れの具体例として位置づけられます。

### 2.6 近距離無線通信：Bluetooth、ZigBee、NFC

有線のインタフェースに対し、近距離を無線で結ぶ規格も複数あります。それぞれ用途に応じて特徴が異なります。

- **Bluetooth**：数メートル〜数十メートル程度の近距離無線通信規格。ヘッドセット、キーボード、スピーカーなど、比較的データ量のある機器同士の無線接続に広く使われます。
- **ZigBee**：Bluetoothよりもさらに低消費電力・低速・低コストに特化した近距離無線通信規格。センサーネットワークやIoT機器など、電池で長期間動作させる必要がある小型機器同士の通信に向いています。
- **NFC（Near Field Communication）**：数センチメートル程度の非常に近い距離でのみ通信できる近距離無線通信規格。交通系ICカードや電子マネー、スマートフォンのタッチ決済など、「かざす」動作で瞬時にやり取りする用途に使われます。

「通信距離・速度・消費電力」という軸で、Bluetooth（中距離・汎用）、ZigBee（低消費電力・IoT向け）、NFC（極近距離・タッチ用途）を対比的に整理すると覚えやすくなります。

### 2.7 IrDA

**IrDA（Infrared Data Association）**は、赤外線を利用した近距離無線通信規格です。電波を使う上記の規格と異なり光（赤外線）を用いるため、通信するには機器同士が向かい合っている（見通せる）必要があり、遮蔽物があると通信できません。かつて携帯電話同士のデータ交換などに使われましたが、Bluetoothなど電波方式の普及により現在は用途が限定的になっています。「無線＝電波」という思い込みに対し、「光（赤外線）による近距離無線通信もある」という点が試験の引っかけポイントになりやすいところです。

## 3. 補助記憶装置 ― データを蓄えるメディア

### 3.1 光ディスク：DVDとBD

**光ディスク**は、レーザー光をディスク表面に照射し、その反射の違いを読み取ることでデータを記録・再生する記憶メディアです。

- **DVD（Digital Versatile Disc）**：CDの後継として登場した光ディスク規格で、数GB程度の記憶容量を持ちます。
- **BD（Blu-ray Disc）**：DVDよりも波長の短い青紫色レーザーを用いることで、より高密度な記録を可能にした光ディスク規格で、数十GB規模の大容量を実現しています。

「DVD→BDへと、より短い波長のレーザーを使うことで大容量化してきた」という技術の流れとして理解しておきましょう。

### 3.2 SSD

**SSD（Solid State Drive）**は、回転するディスクを使う従来のハードディスクとは異なり、半導体メモリ（フラッシュメモリ）を用いてデータを記憶する補助記憶装置です。機械的な駆動部分がないため、ハードディスクに比べて衝撃に強く、読み書きが高速で、静音・省電力という利点があります。前回のノートで扱った「半導体メモリ」の応用の一つとして位置づけられます。

### 3.3 SD、SDHC、SDXC

**SD（Secure Digital）**カードは、デジタルカメラやスマートフォンなどで広く使われる小型のフラッシュメモリカード規格です。記憶容量の上限に応じて、規格が段階的に拡張されてきました。

| 規格 | 対応容量の目安 |
|---|---|
| **SD** | 〜2GB程度 |
| **SDHC（High Capacity）** | 2GB超〜32GB程度 |
| **SDXC（eXtended Capacity）** | 32GB超〜数TB程度 |

「容量の上限が上がるごとに規格名が変わっていく（SD→SDHC→SDXC）」という関係を押さえておけば十分です。

### 3.4 オブジェクトストレージ

これまでのメディアが「物理的な記憶媒体そのもの」の話であったのに対し、**オブジェクトストレージ**は、データを「オブジェクト」という単位（データ本体＋メタデータ＋一意の識別子）で管理する、大規模なデータ保存の**方式**です。従来のファイルシステムのような階層構造（フォルダの中にフォルダ、という木構造）を持たず、フラットな構造の中で大量のオブジェクトを一意のIDで管理するため、クラウドストレージサービスなど、膨大な量の非構造化データ（画像、動画、ログなど）を柔軟かつ大規模に保存する用途に適しています。

### 3.5 シンプロビジョニング

**シンプロビジョニング**は、ストレージの容量をどのように利用者へ割り当てるかに関する、仮想化の考え方の一つです。利用者に対しては「実際に必要な容量よりも大きい容量」を見かけ上割り当てておき、実際に物理的なディスク容量を消費するのは、実際にデータが書き込まれた分だけにとどめる、という方式です。あらかじめ最大容量を丸ごと物理的に確保してしまう従来型の割り当て方式に比べ、実際の使用量に応じて後から物理容量を追加していけるため、ストレージ資源を無駄なく効率的に利用できるという利点があります。

## 4. 試験対策まとめ（重要ポイント）

- **RAIDレベルの対比**：RAID0（ストライピングのみ・速度重視・冗長性なし）／RAID1（ミラーリングのみ・信頼性重視・容量効率悪い）／RAID5（パリティ付きストライピング・1台故障まで耐える・バランス型）／RAID6（パリティ2重化・2台故障まで耐える）という段階的な関係を、キーワード（ストライピング／ミラーリング／パリティ）とセットで整理する。RAID0+1とRAID1+0（RAID10）は、組み合わせる順序によって耐障害性が異なる点（RAID1+0の方が一般に堅牢）に注意。
- **ホットスペアディスク**は「故障時に自動で切り替わる予備ディスク」であり、RAIDの信頼性運用を補完する仕組みとして関連づけて覚える。
- **パラレル伝送からシリアル伝送への流れ**（ATA/IDE→SATA、パラレルSCSIなど）を軸に、USB・IEEE1394・SATAなど現行の主要インタフェースがいずれもシリアル伝送である、という大きな流れを押さえる。
- **USBの速度モード**（ロー／フル／ハイ／スーパースピード）は世代とセットで、**プラグアンドプレイ・ホットプラグ**という2つの利便性のキーワードもあわせて確認する。
- **近距離無線の使い分け**（Bluetooth＝汎用中距離、ZigBee＝低消費電力のIoT向け、NFC＝極近距離のタッチ用途、IrDA＝光による見通し内通信）は表で対比整理しておくと得点しやすい。
- **補助記憶メディアの容量・世代の関係**（DVD→BD、SD→SDHC→SDXC）は、単純な暗記で対応できる頻出論点。
- **オブジェクトストレージ**（フラットな構造でオブジェクト単位に管理）と**シンプロビジョニング**（実使用量に応じた容量割り当て）は、いずれも大規模ストレージ運用を効率化する「方式・考え方」であり、特定の物理メディアではない点に注意する。
