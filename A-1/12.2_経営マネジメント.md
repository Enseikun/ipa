# レクチャーノート：経営戦略 ― 経営マネジメント

対応範囲：情報処理安全確保支援士試験（科目A-1）「経営戦略」＞「経営戦略マネジメント」・「ビジネスインダストリ」（経営戦略手法、マーケティング、経営管理システム）

---

## 0. 全体像 ― なぜこの分野を学ぶのか

前回のノート（情報システム戦略とシステム規格）では、経営とシステムを結びつける計画・調達の視点を見ました。本ノートでは、その土台にある経営そのものの考え方、すなわち企業がどう競争優位を築き、顧客にどう価値を届け、それをどう情報システムで支えるかという経営マネジメントの知識を扱います。

本ノートは、次の3段階のストーリーで説明します。①まず、企業が競争優位をどう築くかという経営戦略の手法群を学びます。②次に、その戦略を顧客との関係にどう落とし込むかというマーケティングの考え方を見ます。③最後に、これらの戦略・マーケティングを実行に移すための情報基盤である経営管理システムを扱います。

本分野は科目A-2の出題対象には含まれない科目A-1のみの分野で、範囲は広いものの個々の配点は薄いため、深追いせず典型論点の名称と特徴の対応を暗記中心に押さえることが効率的です。似た名前の分析手法・戦略類型が多いため、「何を、どの軸で分類するか」を意識して整理します。

---

## 1. 競争優位をどう築くか ― 経営戦略手法

まず、企業が他社との競争にどう向き合い、優位性を築くかという戦略の手法を見ていきます。

### 1.1 競争優位をどう築くか

**競争戦略と差別化戦略**とは、他社との競争にどう挑むかという基本戦略の2方向を指し、価格の低さで勝負するか（コストリーダーシップ）、他社にはない独自性で勝負するか（差別化）という代表的な選択肢を表します。この差別化の源泉として重視されるのが**コアコンピタンス**で、他社が容易に模倣できない、自社の中核的な強み（技術・ノウハウ）を指します。こうした戦略を検討する際、優れた他社の事例と比較して改善点を見出す**ベンチマーキング**（以前のノートでITILの文脈で扱った手法）が、経営戦略一般の手法としても用いられます。

### 1.2 自社の状況を分析する

戦略を立てる前提として、自社や業界の状況を分析する代表的な手法があります。

| 手法 | 分析の視点 |
|---|---|
| **SWOT分析** | 内部要因（強み・弱み）と外部要因（機会・脅威）の4象限で自社の状況を整理する |
| **ファイブフォース分析** | 業界の競争構造を、既存競合・新規参入・代替品・売り手の交渉力・買い手の交渉力という5つの競争要因から分析する |
| **バリューチェーン分析** | 事業活動を機能ごとに分解し、どの活動が付加価値を生んでいるかを分析する |

SWOT分析が「自社の内と外」を見るのに対し、ファイブフォース分析は「業界構造そのもの」を見るという対象の違い、バリューチェーン分析は「事業活動のどこで価値が生まれているか」という工程に着目する点で、それぞれ分析の切り口が異なります。

### 1.3 事業ポートフォリオと成長の方向性

複数の事業・製品をどう位置づけ、どこに成長の機会を見出すかを考える手法もあります。**PPM（プロダクト・ポートフォリオ・マネジメント）**は、市場成長率と市場占有率の2軸で事業や製品を「花形」「金のなる木」「問題児」「負け犬」に分類し、経営資源の配分を検討するフレームワークです。

これに対し、**成長マトリックス**は、「製品」と「市場」がそれぞれ新規か既存かという2軸で、4つの成長戦略に分類します。

- **市場浸透戦略**：既存製品×既存市場（シェア拡大を狙う）
- **新製品開発戦略**：新製品×既存市場
- **新市場開拓戦略**：既存製品×新市場
- **多角化戦略**：新製品×新市場（最もリスクが高い）

PPMが「今ある事業に、どう資源を配分するか」を検討するのに対し、成長マトリックスは「どの方向に新たな成長を求めるか」を検討するという対比で整理すると理解しやすくなります。

### 1.4 戦略を実行し、管理する

戦略を実際の活動に落とし込む手法として、製造原価に一定の利益を上乗せして価格を決める**コストプラス価格決定法**のような基本的な価格設定の考え方があります。より戦略全体を管理する枠組みとしては、財務・顧客・内部プロセス・学習と成長という4つの視点から経営戦略を具体的な指標に落とし込み、実行を管理する**バランススコアカード（BSC）**があります。また、こうした戦略の実行に伴う組織変革を計画的かつ円滑に進めるためのマネジメント手法を**チェンジマネジメント**と呼びます。

### 1.5 単独では実現できない戦略 ― 提携と統合

自社単独では実現しにくい成長を、他社との関係によって実現する手法もあります。**M&A（合併・買収）**は、他企業を合併・買収することで、事業拡大や新規事業への進出を短期間で実現する手法です。これに対し**アライアンス**は、資本関係を持たずに複数の企業が協力関係を結ぶ提携です。M&Aが「一体化する」統合であるのに対し、アライアンスは「独立を保ったまま協力する」提携であるという結合の強さの違いで区別します。さらに、自社の業務プロセスの一部を外部の専門業者に委託する**BPO（Business Process Outsourcing）**もあり、「自社で行うか（内製）」「他社と一体化・提携するか（M&A・アライアンス）」「他社に委ねるか（BPO）」という3つの選択肢として、本節全体を整理できます。

## 2. 顧客にどう価値を届けるか ― マーケティング

経営戦略を、実際の顧客との関係にどう落とし込むかというマーケティングの考え方を見ていきます。

### 2.1 顧客の購買心理をモデル化する

顧客が商品を認知してから購買に至るまでの心理プロセスを表す代表的なモデルが**AIDA理論**で、Attention（注意）→Interest（関心）→Desire（欲求）→Action（行動）という4段階から成ります。このAIDAを基本形として、次のような派生モデルがあります。

| モデル | AIDAに追加される要素 |
|---|---|
| **AIDMA** | Memory（記憶） |
| **AIDCA** | Conviction（確信） |
| **AIDAS** | Satisfaction（購買後の満足） |

AIDAという基本形に、「記憶に残るか」「確信を持てるか」「購買後に満足するか」という異なる要素を1つずつ加えた発展形として整理すると、名称と追加要素の対応が覚えやすくなります。

### 2.2 マーケティングの基本戦略

マーケティング戦略を立てる際の代表的な分析・計画手法として、自社（Company）・競合（Competitor）・顧客（Customer）の3つの視点で市場環境を分析する**3C分析**があります。前章のSWOT分析などが経営全般の分析手法であるのに対し、3C分析は市場・顧客という観点に絞ったマーケティング領域の分析手法です。

具体的な施策は、Product（製品）・Price（価格）・Place（流通）・Promotion（プロモーション）という4要素を組み合わせる**マーケティングミックス（4P）**として計画されます。このうち製品の存在や価値を顧客に伝える活動全般を**プロモーション**と呼び、こうした施策の意思決定に必要な情報を調査によって収集・分析する活動を**マーケティングリサーチ**と呼びます。なお、価格カルテルのような過度な競争制限に陥らないよう、マーケティング活動全体を規制する法律として**独占禁止法**があります。

### 2.3 新しい顧客との関わり方

顧客との関わり方にも、新しい考え方が広がっています。口コミのように、利用者から利用者へ自然に情報が伝播することを狙う**バイラルマーケティング**、顧客一人ひとりの属性・行動に応じて個別に最適化したアプローチを行う**ワントゥワンマーケティング**があります。さらに、大量生産（マス）の効率を保ちながら個々の顧客の要望に応じてカスタマイズした製品・サービスを提供する**マスカスタマイゼーション**は、ワントゥワンマーケティングの考え方を製品そのものの提供方法にまで広げた発展形として位置づけられます。

こうした個別対応が重要になる背景には、製品・サービスの差別化が失われ、価格以外で選ばれなくなる**コモディティ化**という現象があります。1.1節の差別化戦略が機能しなくなった状態として、対比的に押さえておくとよいでしょう。

### 2.4 顧客の体験と価値をどう測るか

商品購入前から購入後まで、顧客が得るすべての体験の総体を**カスタマーエクスペリエンス（CX）**と呼び、これを意図的に設計・管理する活動を**CEM（Customer Experience Management）**と呼びます。顧客の価値を測る指標としては、一人の顧客が取引期間全体を通じて自社にもたらす利益の総額を表す**ライフタイムバリュー（LTV）**、最終購買日・購買頻度・購買金額の3指標で顧客をグループ分けし優良顧客を識別する**RFM分析**、広告費に対してどれだけの売上を生み出したかを示す**ROAS**があります。

LTVが「顧客の生涯を通じた長期的価値」を、RFM分析が「取引履歴に基づく現状の顧客分類」を、ROASが「広告という個別施策の短期的な効果」を、それぞれ異なる時間軸・対象で捉えている点が、これらを区別する着眼点です。

## 3. 戦略とマーケティングを支える情報基盤 ― 経営管理システム

最後に、これまで見てきた戦略・マーケティングを実行するための、情報システムの基盤を見ていきます。

### 3.1 知識を経営に活かす

前回のノートで扱った**ナレッジマネジメント**（組織内の知識・ノウハウを共有・活用する考え方）を実現する理論的なモデルが**SECIモデル**です。言葉で表現しにくい、個人の経験や勘に基づく知識である**暗黙知**と、言葉や図表で表現され共有可能な知識である**形式知**が、共同化（Socialization）→表出化（Externalization）→連結化（Combination）→内面化（Internalization）という4つの過程を経て相互に変換されることで、組織全体の知識が創造されるというモデルです。

### 3.2 顧客との関係を管理するシステム

顧客との関係を一元的に管理し、長期的な関係構築を図るシステム・考え方を**CRM（顧客関係管理）**と呼びます。これに対し、営業活動の進捗・履歴を管理し効率化を図るシステムを**SFA（営業支援システム）**と呼びます。CRMが顧客との関係全般を広く扱うのに対し、SFAは営業活動という特定のプロセスに特化したシステムであるという対象範囲の違いで区別します。

### 3.3 供給網と販売網を管理するシステム

原材料の調達から製造、配送、販売に至る一連の流れ（サプライチェーン）を、企業の枠を超えて統合的に管理する考え方が**SCM（サプライチェーンマネジメント）**です。これに対し、実店舗・ECサイト・アプリなど複数の販売チャネルを統合し、顧客がどのチャネルからでも一貫した体験を得られるようにする考え方が**オムニチャネル**です。SCMが「供給側の流れ」を統合するのに対し、オムニチャネルは「販売側の顧客接点」を統合するという対比で整理できます。

### 3.4 企業の基幹業務を統合するシステム

人・モノ・金・情報といった経営資源を、企業全体で統合的に管理・計画する考え方を**ERP（Enterprise Resource Planning）**と呼び、これを実装した市販の統合基幹業務ソフトウェアを**ERPパッケージ**と呼びます。3.2節・3.3節で見たCRM・SFA・SCMが特定の業務領域に特化したシステムであるのに対し、ERPはそれらを含む企業の基幹業務全体を統合する、より広い範囲のシステムとして位置づけられます。

### 3.5 新規システム導入前の見極めと管理指標

ERPのような大規模なシステムを導入する前には、技術面・コスト面などから実現可能性を事前に調査・検証する**フィージビリティスタディ**が行われます。そして、戦略目標の達成度を測るための具体的で測定可能な指標が**KPI（重要業績評価指標）**で、1章で見たバランススコアカードにおいて戦略を指標に落とし込む際にも、このKPIが用いられます。

## 4. 試験対策まとめ（重要ポイント）

- **SWOT分析 と ファイブフォース分析 と バリューチェーン分析**：自社の内外か、業界構造か、事業活動の付加価値かという分析対象の違い。
- **PPM と 成長マトリックス**：既存事業への資源配分を検討するか、新たな成長の方向性を検討するかの違い。
- **M&A と アライアンス と BPO**：統合するか、独立を保ち協力するか、外部に委ねるかという関わり方の強さの違い。
- **AIDA と AIDMA／AIDCA／AIDAS**：基本形に、記憶・確信・購買後の満足という異なる要素を加えた派生モデルであることを押さえる。
- **CRM と SFA**：顧客関係全般か、営業プロセスに特化するかという対象範囲の違い。
- **SCM と オムニチャネル**：供給側の流れを統合するか、販売側の顧客接点を統合するかの違い。
- **ERP と CRM／SFA／SCM**：企業の基幹業務全体を統合するか、特定の業務領域に特化するかという範囲の違い。
- **LTV と RFM分析 と ROAS**：顧客の生涯価値（長期）か、取引履歴による分類（現状）か、広告効果（個別施策）かという視点の違い。
- **暗黙知 と 形式知 と SECIモデル**：言語化しにくい知識と共有可能な知識が、4つの過程を経て相互に変換されるという循環の関係。
