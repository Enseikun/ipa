# Product Context

## 存在理由 / 解決する課題
情報処理安全確保支援士試験は科目A-1・科目A-2・科目Bの3科目構成で、出題範囲が広範な上に
科目ごとに優先度の性格が大きく異なる（[0.2_出題傾向.md](../0.2_出題傾向.md)参照）。

- 科目A-1: セキュリティ以外は1〜2問ずつ広く薄く出題 → 「広く浅く、セキュリティだけ厚め」。
- 科目A-2・科目B: セキュリティが25問中17問（68%）を占め極端に偏重 → 「セキュリティに極端に集中」。

素の教科書学習では出題傾向に対して学習時間の配分が最適化されず、
非効率になりやすい。この課題を解決するため、優先順位付けされた章立てで
レクチャーノートを1本ずつ作成・蓄積していく。

## 期待するUX（ノートの読み手体験）
[0.0_ガイドライン.md](../0.0_ガイドライン.md) に定義された方針に従い、以下を満たすノートを提供する。

- 単なる用語集ではなく、「なぜこの技術が生まれたか」というストーリーとして読める。
- 頻出の対比構造（例: ROMとRAM、CISCとRISC）が表または対比文で明示されている。
- 前回までのノートで学んだ概念との橋渡しがあり、学習の積み上げ感がある。
- 末尾の「試験対策まとめ」で、対比構造・頻出式・引っかけポイントが凝縮されている。
- 分野の優先順位（[0.3_優先順位.md](../0.3_優先順位.md)）を踏まえた学習配分コメントで締められている。
- 科目A-2・科目Bのノートでは、科目Aの選択式向け知識確認と、科目Bの記述式向け
  「事例でどう問われるか」の2部構成になっている。
