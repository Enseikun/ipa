## 得られた知見
- 長大なノート（1,000行超）は、プレースホルダを置いて複数回に分けて書くと安全。
- 攻撃系の例示を求めると制限で止まる。防御側の例示に絞る（`k-20260930-cyber-content-block`）。
- 改稿の欠落確認は、改稿前の版と太字・英字・カタカナ語・数値を照合する方式が有効。
  git 未登録のファイルは、着手前に改稿前の版を別の場所へ写しておく。
- 原本の「試験に出る」（出題予想）を「試験に出た」（出題実績）に言い換えない。
