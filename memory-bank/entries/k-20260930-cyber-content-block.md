# 攻撃系ノートの改稿依頼はサイバー関連の制限で中断されることがある
- id: k-20260930-cyber-content-block
- tags: a-2b,note,subagent
- updated: 2026/09/30 07:50

## 要点
- 攻撃入力値・攻撃トラフィック・回避手口の「見た目」を例示させる依頼は、Anthropic のサイバー関連の制限で途中停止することがある。
- 停止時は書きかけのファイルが残る。末尾が文の途中で切れていないか確認し、切れていれば `git checkout HEAD -- <file>` で原本に戻してから再依頼する。
- 再依頼では、例示を防御側・運用側が目にするもの（安全な設定、ログの読み方、監視画面、比較表、構成図）に限定し、攻撃の仕組みは原本と同程度の概念説明に留めると完走した。
- ただし「原本にある記述まで削らない」ことを明記する（5.9 で原本の括弧書きが削られ、手で戻した）。

## 根拠
- 2026/09/30 の第2〜5章改稿で、2.1〜2.3・2.4〜2.7・5.6〜5.9 の担当が停止。2.3・2.5・5.8 が途中で切れていた。
- 防御視点に絞った再依頼（2.3、2.5〜2.7、5.8〜5.9）はすべて完了。
