# Tech Context

## 制作形式
- 出力はすべて Markdown。見出しレベルは `#`→`##`→`###` の3階層まで。
- 数式は $$…$$ 形式（MIPS・稼働率・ヒット率など計算問題が頻出する分野で使用）。
- リポジトリは git 管理（ホスティングは特定していない、ローカルgitリポジトリ）。

## 一次情報源と版管理
- `ipa_試験要綱_v5.6.pdf`（Ver.5.6、2026年7月6日改訂、2026年10月の試験から適用）が
  出題範囲・技術レベルの公式一次情報。参照箇所は「7. 出題範囲」の
  〔科目A，科目A-1，科目A-2の出題範囲〕表と〔試験区分別出題分野一覧表〕。
- 要綱は範囲の骨組みまでで、用語の学習目標細目は別冊「シラバス」にある
  （要綱に無い用語でも依頼に含まれる場合は省略しない）。
- 要綱が改訂され新しい版のPDFが追加された場合、`0.0_ガイドライン.md` 9.2節の
  ファイル名・版・制度表記を更新する必要がある（本ファイルの記載もあわせて見直す）。

## 科目別の制約・差分
- 科目A-1: 応用情報技術者試験 科目Aと同一範囲。テンプレートは単一の「試験対策まとめ」。
- 科目A-2・科目B: 支援士専用。セキュリティ・ネットワークは技術レベル4でA-1より深い粒度。
  「試験対策まとめ」は科目A-2向け・科目B向けの2部構成が必須。
- 科目Bは中分類ではなく4つの業務観点（セキュリティマネジメント推進、企画設計開発運用の
  セキュリティ確保、利用時のセキュリティ対策適用、インシデント管理）で出題されるため、
  A-2B配下のノートには「0. 全体像」でどの観点に対応するかの一言が必要。

## 依存関係
- 新規ノート作成前に必ず試験要綱PDFで該当分野の出題範囲を確認する運用
  （[0.0_ガイドライン.md](../0.0_ガイドライン.md) 1節・9節）。
- 既出ノート一覧（[0.0_ガイドライン.md](../0.0_ガイドライン.md) 8節の表）を重複防止の参照台帳として使う。
