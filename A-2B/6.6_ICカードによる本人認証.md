# 6.6_ICカードによる本人認証

## 6.6 ICカードによる本人認証

ICカードとは、キャッシュカード大のプラスチック製カードに極めて薄いICチップ（半導体集積回路）を埋め込み、情報を記録できるようにしたカードのことをいう。磁気ストライプカードと比べて記憶容量が大きく、演算機能を持つため、暗号処理や認証処理をカード内部で実行できる。

ICカードを用いた認証方式は、データを読み書きする方式の違いにより、**接触式**と**非接触式**に分けられる。両者は運用時の利用者の負担や利便性に差があるが、セキュリティレベルに大きな違いはない。

| 方式 | 概要 | 主な利用例 |
|---|---|---|
| 接触式 | カード表面の金属端子をリーダライタの端子に接触させて通信・給電する | キャッシュカード、クレジットカード、社員証（PC ログオン用） |
| 非接触式 | リーダライタにかざし、電磁誘導による無線通信で給電・通信する | 交通系ICカード、入退室管理カード、電子マネー |

> **補足：出題傾向**
> 情報セキュリティスペシャリスト試験や情報処理安全確保支援士試験の午後問題では、ICカードを用いた認証システムのセキュリティ要件や、認証システムの設計を題材とした問題が出題されている。ICカードの仕組みやPKIとの関係は、午後問題の前提知識として問われることが多い。

### 6.6.1 ICカードのセキュリティ機能

#### 耐タンパ性

一般に、ハードウェアやソフトウェアのセキュリティレベルは**耐タンパ（tamper）性**で表される。tamperとは「許可なくいじる」という意味で、耐タンパ性が高いほどセキュリティレベルは高くなる。ICカードの耐タンパ性とは、ICカードに保存された重要データを外部から無理やり取り出したり、盗み読んだりする行為に対抗する耐性のことである。

ICカードは携帯性に優れ、耐タンパ性も高いため、**秘密鍵の保管**に適している。その反面、紛失や盗難による不正使用のおそれがある。ICカードを不正に入手した者によるなりすましへの対策として、PIN（暗証番号）による本人確認に加え、ICカードにバイオメトリクス（生体）認証技術を搭載する方式などが採用されている。

> **用語解説：耐タンパ性**
> 物理的・論理的な手段による内部情報の解析や改ざんに対する抵抗力のこと。ICカードのほか、TPM（Trusted Platform Module）やHSM（Hardware Security Module）などのセキュリティデバイスにも求められる性質である。

#### ICカードによるデータ処理の例

**① データ復号処理**

1. ICカードに格納された「秘密鍵」を用いて、暗号化された暗号鍵（共通鍵）を復号する
2. 復号された「暗号鍵」を用いてデータを復号する

**図：ICカードを用いたデータ復号処理の例**

```
[暗号化された暗号鍵] ──▶ ICカード内（秘密鍵で復号） ──▶ [暗号鍵]
                                                          │
[暗号化されたデータ] ─────────────────────────────▶ 暗号鍵で復号 ──▶ [平文データ]
```

この方式は、公開鍵暗号方式と共通鍵暗号方式を組み合わせたハイブリッド暗号方式であり、処理の重い公開鍵暗号は鍵の復号のみに用い、データ本体は高速な共通鍵暗号で復号する。

**② デジタル署名処理**

1. デジタル署名の対象データをハッシュ化し、メッセージダイジェスト（MD）を生成する
2. ICカードに格納された「秘密鍵」を用いてMDを暗号化し、デジタル署名を生成する

ICカード内で署名生成処理を行うことにより、秘密鍵がカード外部に漏れない。また、カードの受付が可能な任意の端末で安全に署名を生成できる。

> **関連知識：PKI**
> PKI（Public Key Infrastructure：公開鍵基盤）とは、公開鍵暗号方式を用いて実現されるさまざまなセキュリティ技術の基盤である。認証局（CA）が発行するデジタル証明書により、公開鍵とその所有者の対応関係を保証する。ICカードは、PKIにおける秘密鍵とデジタル証明書の安全な格納媒体として活用される（例：マイナンバーカードの電子証明書）。詳細は7.7節で解説する。

### 6.6.2 ICカードの脆弱性

#### ICカードに対する攻撃手法

ICカードに対する攻撃手法は、ICチップの破壊を伴うか否かによって次のように大別される。

**破壊攻撃**

- ICチップを破壊して集積回路に直接アクセスする攻撃
- 代表的な攻撃手法には、プロービングやリバースエンジニアリングがある
- 非破壊攻撃に比べて多くのコストがかかる

**非破壊攻撃（サイドチャネル攻撃とも呼ばれる）**

- ICチップを破壊することなく、外部から観察可能な情報や、外部から操作可能な手段を利用して情報を奪取する攻撃
- 攻撃のコストは低く済むが、破壊攻撃と比較すると情報奪取までに時間を要する
- 代表的な攻撃手法には、DPA、SPA、グリッチ、光照射、タイミング攻撃がある

**表：ICカードに対する攻撃手法の例**

| 攻撃の種類 | 攻撃手法 | 内容 |
|---|---|---|
| 破壊攻撃 | プロービング | ICチップの配線パターンに直接針（プローブ）を当てて、内部を流れる信号を読み取る手法 |
| 破壊攻撃 | リバースエンジニアリング | ICチップを観察して機能やセキュリティ機構に関する情報を得る手法。暗号鍵の推定などには直接つながらないが、他の攻撃の準備段階として利用される |
| 非破壊攻撃 | DPA（Differential Power Analysis） | 多数の消費電流波形を統計処理して暗号鍵を推定する手法 |
| 非破壊攻撃 | SPA（Simple Power Analysis） | ICチップの消費電流波形を比較・解析して、処理内容や暗号鍵を推定する手法 |
| 非破壊攻撃 | グリッチ（glitch） | 一時的にクロック周波数や電源電圧を変化させるなどして、誤ったデータの入力をサンプリングさせたり、フリップフロップの誤動作を起こしたりし、正常動作時の出力との違いから秘密情報を推定する手法 |
| 非破壊攻撃 | 光照射 | ICチップにレーザ光などを照射して誤動作（故障）を誘発し、その出力から秘密情報を推定する手法 |
| 非破壊攻撃 | タイミング攻撃 | 暗号化や復号に要する処理時間を測定し、その差から暗号鍵を推定する手法 |

> **補足：故障利用攻撃**
> グリッチや光照射のように、意図的に誤動作を起こさせ、誤った演算結果と正しい演算結果の差分から秘密情報を推定する攻撃は、故障利用攻撃（フォールト攻撃、DFA：Differential Fault Analysis）とも呼ばれる。

#### ICカードに対する攻撃への対策

ICカードに対する攻撃への主な対策は、ICチップの構造に関するものとなる。これらはいずれも、ICカードを導入・利用する側の取組みによって効果を得られるものではないが、製品選定の際の参考情報として認識しておくとよい。

- **各種センサによる対策**
  周波数、電圧、温度、光などに関するセンサを搭載し、仕様範囲外の動作環境に置かれた場合には、CPUをリセットしたり、チップが動作しなくなるようにしたりする（グリッチや光照射への対策）。
- **配線の多層化**
  重要な回路は可能な限り下層に配線し、上層部をはぎ取ると回路そのものが破壊される設計にする（プロービングへの対策）。
- **動作クロックの内部生成**
  チップの内部動作に使用するクロックをチップ内部で生成することで、攻撃タイミングの同期をとることを困難にする。
- **メモリチェック機構の工夫**
  ECC（Error Correcting Code）やパリティチェック機構を導入し、データの改変や誤動作を検出する。
- **暗号アルゴリズム実装方法の工夫**
  処理時間や消費電力が秘密情報に依存しないようにアルゴリズムを実装する。例えば、鍵のビット値にかかわらず同一の処理時間となるようにダミー演算を加える（タイミング攻撃やSPA/DPAへの対策）。
- **テスト回路の削除**
  出荷後にテスト回路を使用不可能な状態にし、製造時のテスト用インタフェースを経由した内部情報の読み出しを防ぐ。

#### ICカード（チップ）の脆弱性評価

ICチップの脆弱性評価に関する事実上の基準となっているのは、**JIWG（European Joint Interpretation Working Group）**が作成した文書である。JIWGは、ICカードの評価の公平性や客観性を実現するための共通の解釈指針を策定しており、評価に用いられる部材などを含めた基本モデルの提供や、攻撃者の心理状態の解析、攻撃所要時間に対する実現性の見解なども記載されている。

> **用語解説：コモンクライテリア（ISO/IEC 15408）**
> IT製品のセキュリティ機能を評価するための国際標準。ICカードの評価においては、JIWGによる解釈文書（例：攻撃能力の算定方法）を補足資料として用い、攻撃に要する時間、専門知識、機材などから攻撃の実現可能性を定量的に評価する。

### 6.6 理解度チェック

- 【Q1】ICカードを用いた認証システムにはどのような種類があるか。
- 【Q2】ICカードの耐タンパ性とは何か。
- 【Q3】ICカードはPKIにおいてどのように活用されているか。
- 【Q4】ICカードへの攻撃にはどのようなものがあるか。
- 【Q5】ICカードのセキュリティを高めるための対策としてどのようなものがあるか。

### 確認問題

サイドチャネル攻撃の手法であるタイミング攻撃の対策として、最も適切なものはどれか。

- ア　演算アルゴリズムに処理を追加して、秘密情報の違いによって演算の処理時間に差異が出ないようにする。
- イ　故障を検出する機構を設けて、検出したら秘密情報を破壊する。
- ウ　コンデンサを挿入して、電力消費量が時間的に均一になるようにする。
- エ　保護層を備えて、内部のデータが不正に書き換えられないようにする。

［情報処理安全確保支援士試験・令和5年度］

#### 解答・解説

**正解：ア**

サイドチャネル攻撃とは、耐タンパ性を備えたICカードやTPM（Trusted Platform Module）などに対し、物理的に破壊することなく、外部から観察可能な情報や外部から操作可能な手段を利用して、暗号鍵などの機密情報を奪取する手法である。タイミング攻撃は、暗号化や復号に要する時間を測定することで、用いられている鍵を推測する手法であるため、鍵の違いによって演算の処理時間に差異が生じないようにすることが対策となる。したがって、アが正解である。

- イ：故障利用攻撃（グリッチ、光照射など）への対策である。
- ウ：電力解析攻撃（SPA、DPA）への対策である。
- エ：プロービングなどの物理的な改ざん・解析への対策である。
