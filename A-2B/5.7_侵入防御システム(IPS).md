# 情報セキュリティ対策技術(1)侵入検知・防御

## 5.7 侵入防御システム(IPS)

侵入防御システム(Intrusion Prevention System:IPS)とは、従来のNIDS(ネットワーク型侵入検知システム)を発展させた製品です。ネットワークにインライン接続することで、NIDSと同等の侵入検知機能と、NIDSよりも強力な防御(遮断)機能を備えています。ここでは、IPSの主な機能、構成、運用上の課題などを解説します。

### 5.7.1 IPSの概要

NIDSの導入によって、ファイアウォールをすり抜けてくる不正なパケットや、内部セグメントで発生したマルウェアを検知できるようになりました。しかし、NIDSはファイアウォールのようにインライン接続されるわけではなく、あくまでもネットワークに接続される一つの機器にすぎません。そのため防御機能には限界があり、検知した不正アクセスや攻撃を遮断することは困難でした。

その結果、NIDSを導入しているサイトでは、チューニングや運用管理にコストがかかる割に、実質的な効果がそれほど得られないという問題が指摘されてきました。

IPSは、NIDSの攻撃遮断機能を強化することで、ネットワーク環境のセキュリティを高めることを目的とした製品です。

> **備考:IPSの呼称**
> IPSは製品によって、IDPS(Intrusion Detection and Prevention System)やIDP(Intrusion Detection and Prevention)などと呼ばれることもあります。

#### IPSの接続方法とその特徴

IPSには、次の二つの接続方法があります。

**(1) プロミスキャスモードでの接続**

通常のNIDSと同じ接続方式です。スイッチのミラーポート(SPANポート)などに接続し、ネットワークを流れるパケットを経路外からキャプチャして監視します。IPSがトラフィックに影響を与える可能性は低いものの、防御機能のレベルはNIDSと変わりません。

**(2) インラインモードでの接続**

ファイアウォールと同様に、監視対象の通信が通過するように通信経路上に設置する方式です。すべてのパケットがIPSを経由するため、不正なパケットを検知した時点で確実に遮断できます。一方で、IPSの処理性能や障害がネットワーク全体に直接影響を及ぼすことになります。

```
【プロミスキャスモードでの接続】

  インターネット ─── FW ─── スイッチ ─── 内部ネットワーク
                              │(ミラーポート)
                             IPS

【インラインモードでの接続】

  インターネット ─── FW ─── IPS ─── スイッチ ─── 内部ネットワーク
```

*図:IPSの二つの接続方法*

> **用語解説:プロミスキャスモード**
> ネットワークインタフェースが、自分宛て以外のパケットも含めて、受信したすべてのパケットを取り込む動作モードです。NIDSやパケットキャプチャツールで利用されます。

### 5.7.2 IPSの主な機能

IPSの主な機能を次に示します。IPSはNIDSを継承・強化する製品です。新たな機能が追加されていますが、以前からNIDSに備わっていた機能についても、ほぼそのまま使えると考えてかまいません。

#### 検知機能

基本的には従来のNIDSの検知機能(シグネチャ型検知、アノマリ型検知)を継承しています。ただし、インライン接続で使用する場合は誤検知がそのまま正常な通信の遮断につながります。そのため、フォールスポジティブを低減するための検知精度の向上が図られています。

#### 遮断機能

インライン接続により、不正なパケットを完全に遮断できるようになりました。

NIDSのTCPコネクション切断機能(RSTパケットの送出など)では、少なくとも最初に攻撃を検知したパケットはターゲットとなったホストに到達してしまいます。そのため、攻撃を完全に遮断することは不可能でした。これに対しIPSでは、最初の攻撃パケットも含めて遮断できます。

どのような事象が発生した場合に遮断するのかは、詳細に設定できます。なお、一般的なIPSは従来のNIDSの遮断機能(ファイアウォールとの連携による遮断機能など)も備えているため、それを使って防御することも可能です。

#### パケットの方向に応じたポリシ設定機能

ポリシとは、攻撃の検知や、検知後のアクションに関する詳細な設定のことです。IPSをインライン接続で使用する場合は、パケットの方向(インバウンド/アウトバウンド)ごとに異なるポリシを設定できます。これにより、ファイアウォールのACL(アクセス制御リスト)と組み合わせて、無駄のない効率的なポリシ設定が可能になりました。

#### VLAN環境での仮想IPS機能

VLAN環境において、1台のIPSを用いて各ブロードキャストドメインに仮想的なIPSを設置する機能です。これにより、1台のIPSで複数のセグメントを同時に監視・防御でき、しかもセグメントごとに異なるポリシを適用できます。

このほか、従来のNIDSが備えている次の機能も使用できます。

- イベント検知後の各種アクション実行機能(管理者への通知など)
- ログ出力機能
- レポーティング機能

### 5.7.3 IPSの構成例

#### DMZでのIPSの使用例

DMZにインライン接続し、公開サーバに対する攻撃を防御する例を示します。

```
  インターネット
        │
       FW ────── IPS ────── DMZ(Webサーバ、メールサーバ、DNSサーバなど)
        │
   内部ネットワーク
```

*図:DMZでのIPSの使用例*

ファイアウォールで許可された公開サービス宛ての通信(HTTP/HTTPS、SMTPなど)の中に含まれる攻撃を、IPSが検知・遮断します。ファイアウォールだけでは防げない、アプリケーション層の攻撃への対策として有効です。

#### 特定システムへの経路上でのIPSの使用例

パッチの適用が困難なシステムへの経路上にインライン接続し、仮想的なパッチ(バーチャルパッチ)として機能させる例を示します。

```
  クライアント群 ─── スイッチ ─── IPS ─── パッチ適用が困難なシステム
                                          (制御システム、レガシーシステムなど)
```

*図:特定システムへの経路上でのIPSの使用例*

脆弱性を突く攻撃パケットをIPSが遮断することで、パッチを適用するまでの間、あるいはパッチを適用できないシステムを保護できます。

> **用語解説:仮想パッチ(バーチャルパッチ)**
> システム本体を修正せずに、IPSやWAFなどで脆弱性を悪用する通信を遮断することで、パッチを適用したのと同等の防御効果を得る手法です。

### 5.7.4 IPSの機能上の限界及び運用上の課題

#### 検知機能における課題

IPSはNIDSの検知機能を継承しつつ、精度の向上を図っています。とはいえ、IPSでもNIDSと同様に次のような問題を抱えています。

- フォールスポジティブ(誤検知)やフォールスネガティブ(検知漏れ)を完全になくすことはできない
- シグネチャ型検知では、シグネチャが用意されていない未知の攻撃を検知できない
- 暗号化されたパケットは、そのままでは内容を解析できない
- 暗号化パケットの復号/解析機能を使用する場合、パフォーマンスの低下は避けられない

> **用語解説:フォールスポジティブとフォールスネガティブ**
> フォールスポジティブ(False Positive)は、正常な通信を不正と誤って判断することです。フォールスネガティブ(False Negative)は、不正な通信を見逃して正常と判断してしまうことです。

#### 防御における課題

インライン接続によってパケットを遮断する場合、前述のとおり、フォールスポジティブが発生すれば正常なアクセスまで遮断されてしまいます。逆に、フォールスネガティブが発生すれば攻撃を見逃してしまいます。導入時には検知のみのモードで運用して誤検知の傾向を把握するなど、十分なチューニングが必要です。

#### IPSの信頼性や可用性に関する課題

インライン接続され、防御機能を有効に設定したIPSは、ファイアウォールと同様にネットワークにおける関所的な存在になります。そのため、IPSの処理性能や可用性がそのままネットワークに影響を及ぼします。したがって、次のような対策を施す必要があります。

- 十分な処理能力を有した製品の使用
- IPSの冗長化、負荷分散
- 電源などの設備障害対策
- SNMPなどを用いたIPSの稼働監視

一般的なIPSでは、障害が発生した場合にパケットをそのまま通過させ、トラフィックが遮断されないようにすることも可能です。これをフェールオープン機能と呼びます。

> **備考:フェールオープンとフェールクローズ**
> フェールオープンは、障害時に通信を通過させて可用性を優先する方式です。フェールクローズ(フェールセキュア)は、障害時に通信を遮断して安全性を優先する方式です。どちらを採用するかは、保護対象システムの要件に応じて判断します。

#### 解答・解説

**解答:エ**

IPSやNIDSは、シグネチャとのパターンマッチング(シグネチャ型検知)と、異常検知(アノマリ型検知)という二つの方式で攻撃や不正アクセスを検知します。

シグネチャ型では、取り込んだパケットと、シグネチャとして定義された攻撃や異常な通信のパターンとを比較し、合致した通信を不正と判断します。また、IPSのインラインモードは、監視対象の通信を通過させるように経路上に設置する方式です。これによって、攻撃や不正アクセスを確実に遮断できます。

- **ア、イ**:インラインモードではなく、プロミスキャスモードの説明です。
- **ウ**:「通常時の通信から外れた通信」を不正とするのは、アノマリ型検知の説明です。
- **エ**:正しい記述です。
